# 架构

[English Version](architecture.md)

## 组件

- `web`：移动优先的 PWA 壳层，用于浏览相册时间线、查看存储节点状态、创建上传会话
- `api`：云端控制面，负责相册成员、RBAC、时间线查询、上传会话与 agent 协调
- `agent`：出站式 NAS 连接器，负责自注册、心跳、轮询任务，并模拟文件处理完成

## 为什么这样设计

大多数目标家庭并没有稳定的公网 IPv4，也不适合把 NAS 直接暴露到公网。当前架构把控制面设计成公开入口，而存储节点只保留出站连接，在家里完成媒体处理工作。

## 当前契约

- Web 读取 `bootstrap`、`timeline` 和 `members`
- 创建上传后，会生成一条绑定到存储节点的媒体处理任务
- agent 轮询待处理任务，并把它们标记为完成
